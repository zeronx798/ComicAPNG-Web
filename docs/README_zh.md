# ComicAPNG Web 简体中文使用指南

ComicAPNG Web 是 [ComicAPNG Desktop](https://github.com/zeronx798/ComicAPNG) 的浏览器与 PWA 版本。创建、提取和阅读过程全部在本地浏览器中完成。漫画文件不会上传到服务器，也没有账户、云存储、分析统计或遥测。

首次成功打开后，应用外壳会由 Service Worker 缓存。之后即使断开网络，仍可重新打开并使用创建、提取和阅读功能。

## 创建 APNG 漫画

1. 打开“创建”，点击“添加图像”，或在桌面设备上将多张图像拖入页面。
2. 新文件会按文件名自然排序，例如 `2.png` 位于 `10.png` 之前。
3. 桌面端可使用 Ctrl 或 Command 多选、Shift 连选、框选和拖动排序。
4. 手机和平板触控布局可进入明确的“选择”模式，然后使用全选、删除、设为封面、向前移动、向后移动、移到开头或移到末尾。
5. 封面在导出时会移动到第 0 帧，不会重复出现。
6. 可设置封面与正文页面时长。默认值分别为 10.000 秒和 5.000 秒。
7. 可选填写标题和作者，它们会作为 PNG iTXt 文本写入。
8. 点击“导出 APNG”下载文件。

所有页面使用同一画布。画布宽度和高度分别取所有源页面的最大值。图像只按一个比例缩放并居中，不会拉伸、裁切，也不会填充黑色或白色。剩余区域保持完全透明。

## 提取页面

1. 打开“提取”，选择或拖入 PNG/APNG 文件。
2. 应用会显示检测类型、帧数、画布大小和基本元数据摘要。
3. Chromium 浏览器可以选择输出文件夹。其他浏览器会下载 ZIP 压缩包。
4. 输出文件始终按 `1.png`、`2.png`、`3.png` 的方式连续命名。

提取通用 APNG 不需要 ComicAPNG 私有元数据。有效的用户 PNG 文本与原始 PNG `eXIf` 数据会尽可能保留；容器级 ComicAPNG 私有 JSON 不会复制到每张页面。

## 阅读漫画

1. 打开“阅读”，选择或拖入 PNG/APNG 文件。
2. 使用上一页、下一页、页码输入或缩略图跳转。
3. 可放大、缩小、适合页面、适合宽度和全屏。
4. 可选择从左到右或从右到左。方向会影响键盘水平箭头、点击区域与滑动手势。
5. 手机支持滑动翻页和双指缩放，并可隐藏控件以优先显示漫画内容。

阅读是手动的。APNG 中保存的动画时长不会强制自动翻页。阅读进度保存在本机 IndexedDB 中，不会写回漫画，也不会上传。

## 语言、离线与更新

在“设置与关于”中可以切换英语和简体中文、查看版本、提交 SHA、构建时间与更新状态。

更新提示不会自动弹出对话框，也不会在编辑漫画时自动刷新。检测到新版本后，只会显示小型状态标记；用户可在设置中选择“重新加载并更新”。离线或检查失败时，应用仍可正常处理本地漫画。

## 浏览器说明

目标是现代 Chromium、Firefox 和 WebKit/Safari。标准文件选择与下载是所有浏览器的基础路径。文件夹直接写入属于渐进增强功能，不是核心功能的硬依赖。

超大画布和页数很多的漫画仍会受到设备内存与浏览器图像解码限制。本版本不声称支持任意大小的漫画，也不提供任意 EXIF 编辑、双页阅读或按 APNG 时间自动播放。
